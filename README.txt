koldsleep Title / Post Maker — v3.1 Mobile Release
작성일: 2026-10-08

바로 시작
1. ZIP을 풀어 index.html, manifest.webmanifest, assets 폴더를 함께 유지하세요.
2. Mac에서는 index.html을 Safari 또는 Chrome으로 열어 사용할 수 있습니다.
3. iPhone에서는 아래 배포 방법으로 올린 HTTPS 주소를 Safari에서 여세요.

배포
- ZIP 안의 내용 전체를 정적 웹 호스팅의 공개 폴더에 업로드하세요.
- index.html이 첫 화면입니다. 별도 설치, 빌드, 서버 프로그램은 필요 없습니다.
- 하위 폴더 배포도 가능합니다. 모든 경로는 상대 경로입니다.
- manifest.webmanifest는 application/manifest+json 또는 application/json,
  woff2 파일은 font/woff2로 제공하는 것을 권장합니다.
- HTTPS를 사용하세요. 파일 공유와 홈 화면 웹앱 사용에 적합합니다.
- 이 패키지는 배포 파일이며 특정 호스팅에 업로드되어 있지는 않습니다.

iPhone 사용 순서
1. 미리보기를 확인하고 아래에서 텍스트를 편집하세요.
2. 콘텐츠 유형과 출력 규격, 색상, 정렬을 선택하세요.
3. 아래 고정된 'PNG 만들기 · 저장 / 공유'를 누르세요.
4. 준비 완료 창에서 '공유 · 사진에 저장'을 누르고 공유 메뉴의
   '이미지 저장'을 선택하세요. 공유 대상/문구는 iOS 환경에 따라 달라집니다.
5. 공유를 사용할 수 없으면 'PNG 파일 저장'을 누르거나, 완성 이미지를
   길게 눌러 이미지 저장 메뉴를 사용하세요.
6. 홈 화면에서 사용하려면 Safari 공유 메뉴 → '홈 화면에 추가'를 선택하세요.

유지한 기능
- 타이틀: 텍스트에 맞춘 박스. 게시글: 고정 폭 안에서 자동 줄바꿈/높이.
- Instagram 1080 × 1350 (4:5), X/Twitter 1600 × 900 (16:9), 사용자 지정.
- 게시글 기본 박스 폭 44%, 25–80% 조절.
- 흰 배경/검정 박스/흰 글자 또는 검정 배경/흰 박스/검정 글자.
- 왼쪽/중앙/오른쪽/양쪽 정렬, 텍스트 블록 거울 반전.
- koldsleep과 콜드슬립 글자별 랜덤 폰트, 영문 대소문자 랜덤.
- 각 대상 단어에 Galmuri 픽셀 폰트 최소 한 글자 포함.
- 배경 사진, 픽셀화, 흑백, 블러, Black/White point, Gamma, 대비.
- PNG 출력. 박스 안쪽 여백 0은 실제 0px이며 자동 추가 여백이 없습니다.

모바일 개선
- 한 열 화면, 미리보기 우선, 16px 입력, 44px 이상 터치 영역.
- 화면 가장자리 safe-area, 하단 저장 버튼, 접을 수 있는 배경 효과.
- PNG 준비 후 저장/공유 선택. 공유 취소/지원 불가 시 대체 저장 안내.
- 타이틀/게시글 텍스트를 각각 유지하고 주요 설정을 브라우저에 자동 저장.
- 홈 화면용 메타 태그, manifest, 180/192/512px 아이콘.
- Galmuri 7/9/11/14 폰트 파일 동봉. 외부 CDN을 요청하지 않습니다.
- canvas filter가 없는 브라우저에는 픽셀 기반 블러 대체 처리.

알아두기
- 텍스트와 배경 사진은 서버에 업로드되지 않고 기기 안에서 처리됩니다.
- 자동 저장은 현재 브라우저의 로컬 저장소를 사용합니다. 저장소 삭제 또는
  개인정보 보호 모드에서는 복원이 제한됩니다.
- 배경 사진/효과값/글자별 랜덤 선택은 새로 열 때 복원되지 않습니다.
- JPG/PNG를 권장합니다. 읽을 수 없는 사진은 다른 형식으로 변환하세요.
- 큰 사진은 최대 긴 변 4096px 및 1,200만 픽셀 범위로 줄여 처리합니다.
- 출력은 각 변 200–8000px, 전체 1,600만 픽셀 이하입니다.
  휴대폰에서는 Instagram 또는 X 규격을 권장합니다.
- 아주 긴 내용이나 큰 글자/여백은 캔버스 밖으로 나갈 수 있습니다.
  미리보기에서 확인하고 폰트 크기 또는 내용을 조절하세요.
- Mac 전용 기본 글꼴은 다른 운영체제에서 대체될 수 있습니다.
- 홈 화면 설치는 지원하지만 오프라인 캐시(service worker)는 포함하지 않습니다.
  호스팅된 페이지를 다시 열 때는 네트워크가 필요할 수 있습니다.
- 최신 Safari/Chrome을 권장합니다. iPhone에서 파일 앱의 HTML 미리보기보다는
  배포된 HTTPS 주소를 Safari로 열어 사용하세요.

- 타이틀/게시글, 규격, 테마, 정렬, 배경 효과, PNG 출력/다운로드 확인.
- v3.1 원본과 타이틀/게시글/여백 0/정렬/거울 출력 이미지 동일성 비교.
